# Akanksha Chat

A simple Kotlin Android chat UI.

## Current version
- Chat list
- Chat screen
- Send messages locally
- Message timestamps
- Simple Material-style interface

## Open in Android Studio
1. Extract the ZIP.
2. Open the `AkankshaChat` folder in Android Studio.
3. Let Gradle sync.
4. Run on an Android emulator or connected phone.

## Important
This version stores messages only in memory. It is not yet a real internet chat between two phones.

For real two-device messaging, the next version can add Firebase Authentication, Firestore/Realtime Database, and push notifications.
